Support

Found a bug or have an idea? Open an issue on GitHub, for both bug reports and feature requests, or use the Feedback links in the settings window.

Report a bug Request a feature See what others have reported

Each button opens a short form on GitHub, which needs a GitHub account. Without one, write to support@streamkek.com.

Before you report a bug

  • Reload the Twitch tab and see if it still happens.
  • Turn off your other Twitch extensions and check again, since they can change the same parts of the page.
  • The form asks which browser you use, StreamKEK's version, shown at the bottom left of the settings window, and what you were watching: a Twitch stream, a Twitch video, a YouTube stream or a Kick stream.

If something's off

"Sign in to chat" in Brave
If chat says this while you are signed in to YouTube or Kick, open Brave Shields on twitch.tv and allow cross-site cookies.
A Kick stream keeps loading
Open kick.com in a normal tab and answer its cookie prompt once.
No notifications
Check that your computer lets the browser show notifications, and that Do Not Disturb or a Focus mode is not holding them back.
Streams lag on a second screen
If your screens have different refresh rates, like 170 Hz and 60 Hz, streams can lag on the slower one while the browser is the selected window, especially with several open. Chrome and Brave both do this. The easiest fix is to move the browser to your fastest screen.
Something stopped working
StreamKEK relies on how Twitch, YouTube and Kick build their pages, so their updates can break parts of it. First reload the Twitch tab. If it still happens, report it.

Moving to a new computer

Open the settings window and save a backup. It holds your settings, channels, favorites and chat words, and no sign-ins. Restore it from the same place after installing StreamKEK again.

Elsewhere

  • The changelog says what each version added. The settings window shows it too, under What's new.
  • The code is public on GitHub, and CONTRIBUTING.md covers how it is laid out and how to send a change.
  • For anything that doesn't fit an issue, write to support@streamkek.com.
